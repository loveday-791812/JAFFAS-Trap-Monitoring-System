Settings Help

Control default behaviour across the dashboard

  • Overdue threshold — how many days a trap can go without a reset before it's flagged overdue.
  • Default dashboard view — which date range the Dashboard opens to when you visit it.
  • Default report frequency — which report types are pre-selected when adding a new recipient.
  • Email notifications — a master switch for all outgoing report emails.
