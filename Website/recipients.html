Recipients Help

Manage who recieves trap catch report emails.

  • + Add Recipient — add a new person to recieve reports.
  • Report dropdown — change how often that person gets emailed (Daily, Weekly, Monthly).
  • Edit — update the recipient's name, email, and report frequency.
  • Remove — permanetly delete a recipient. Use Pause via Edit instead if its temporary.
