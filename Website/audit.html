Auditt Log Help

Audit Log shows who did what and when, The server writes every entry so that no body can edit or delete them from the website.

  • Show — pick one type of event: accounts and roles, sign ins, data changes or security.
  • Search — type an email address, a trap or an event name
  • Refresh — Loads the newest 100 events.Load older events adds the 100 before them.
  • Security — events are shown in red: lockouts after too many wrong codes, refused admin actions and role changed outside Trapwatch.
